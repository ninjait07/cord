# Cord

**เพิ่มจอให้ Mac ด้วยแท็บเล็ตที่มีอยู่แล้ว** Cord เปลี่ยนแท็บเล็ต Android ให้เป็นจอเสริมของ Mac ผ่านสาย USB-C เส้นเดียวกับที่ใช้ชาร์จ

## ทำอะไรได้

- **สายเดียวจบ** ภาพและการแตะวิ่งผ่านสาย USB-C ไม่ผ่าน Wi-Fi ใช้ได้แม้ไม่มีเน็ต และแท็บเล็ตได้ชาร์จไปด้วยระหว่างใช้
- **เป็นจอจริงของ macOS** ลากหน้าต่างไปวางได้ จัดตำแหน่งจอได้ เลือกความละเอียดได้ เหมือนต่อจอนอก
- **คมเต็มความละเอียด** ส่งภาพเท่าความละเอียดจริงของแท็บเล็ต ตัวหนังสือคมแบบจอ Retina และลื่นได้ถึง 120 fps ถ้าจอแท็บเล็ตรองรับ
- **แตะแบบแท็บเล็ต** แตะเพื่อคลิก ลากเพื่อเลื่อน กดค้างแล้วลากเพื่อย้ายของ หรือสลับเป็นแบบเมาส์ก็ได้
- **หมุนได้ทุกแนว** แนวนอน แนวตั้ง กลับหัว หรือหมุนตามแท็บเล็ตเองเมื่อพลิกเครื่อง
- **Dock ไม่ย้ายหนี** ปกติถ้าวางจอเสริมไว้ใต้จอหลัก macOS จะย้าย Dock ลงไป Cord ทำให้ Dock อยู่ที่จอหลักเหมือนเดิม
- **ไม่ต้องเปิดโหมดนักพัฒนา** ไม่ต้องเปิด USB debugging
- **เล็กมาก** แอปฝั่ง Mac โหลดแค่ราว 1 MB อยู่บนแถบเมนู แอปฝั่งแท็บเล็ตเล็กกว่า 1 MB

## เริ่มใช้

1. โหลด **Cord สำหรับ Mac** จากหน้า [Releases](https://github.com/ninjait07/cord/releases/latest) เปิดไฟล์ แล้วลาก Cord ไปไว้ใน Applications
2. เปิด Cord แล้วอนุญาต **Screen Recording** กับ **Accessibility** เมื่อ macOS ถาม
3. ติดตั้ง **Cord** บนแท็บเล็ตจาก [Google Play](https://play.google.com/store/apps/details?id=com.nonbannawat.cord)
4. ต่อสาย USB-C ระหว่างสองเครื่อง แล้วกด **อนุญาต** บนแท็บเล็ต แท็บเล็ตจะกลายเป็นจอทันที

ต้องมี Mac ที่ใช้ชิป Apple Silicon และ macOS 14 ขึ้นไป แท็บเล็ต (หรือมือถือ) Android 8 ขึ้นไป และสาย USB-C ที่ส่งข้อมูลได้ สายชาร์จอย่างเดียวบางเส้นใช้ไม่ได้

แอปฝั่ง Mac เซ็นด้วย Developer ID และผ่านการตรวจ (notarize) จาก Apple แล้ว เปิดได้โดยไม่มีคำเตือนความปลอดภัย

## การแตะ

| บนแท็บเล็ต | แบบแท็บเล็ต (ค่าเริ่มต้น) | แบบเมาส์ |
| --- | --- | --- |
| แตะ | คลิก | คลิก |
| แตะสองครั้ง | ดับเบิลคลิก | ดับเบิลคลิก |
| ลาก | เลื่อนหน้า ปล่อยนิ้วแล้วไหลต่อ | ลากเมาส์ |
| กดค้าง แล้วลาก | ย้ายหน้าต่าง ลากไฟล์ เลือกข้อความ | |
| กดค้าง แล้วปล่อย | คลิกขวา | คลิกขวา |
| แตะสองนิ้ว | คลิกขวา | คลิกขวา |
| ลากสองนิ้ว | เลื่อนหน้า | เลื่อนหน้า |

ระหว่างที่นิ้วแตะจอ ตัวชี้เมาส์จะหลบไป พอยกนิ้วก็กลับมาอยู่ที่เดิม

## หน้าต่างตั้งค่า

Cord อยู่บนแถบเมนู ทุกอย่างที่ปรับได้อยู่ในหน้าต่างเดียว

<p align="center"><img src="docs/img/panel.png" width="364" alt="หน้าต่างของ Cord"></p>

- **Resolution** ขนาดพื้นที่ทำงานบนแท็บเล็ต ค่าเริ่มต้นคมที่สุด
- **Orientation** หมุนตามแท็บเล็ต แนวนอน แนวตั้ง หรือกลับหัวของแต่ละแนว
- **Quality** และ **Frame Rate** เปลี่ยนได้ระหว่างใช้งาน
- **Keep Dock on Main Display** เปิดไว้เป็นค่าเริ่มต้น มีผลเมื่อจัดแท็บเล็ตไว้ใต้จอหลัก
- **Touch** แบบแท็บเล็ต หรือแบบเมาส์

## สิทธิ์ที่ขอและความเป็นส่วนตัว

ภาพหน้าจอเดินทางจาก Mac ไปแท็บเล็ตผ่านสาย USB เท่านั้น Cord ไม่มีบัญชีผู้ใช้ ไม่มีการเก็บสถิติ ไม่มีโฆษณา

- **Screen Recording** ใช้ส่งภาพของจอเสริมที่ Cord สร้างขึ้น ไม่มีการบันทึกเก็บไว้
- **Accessibility** ใช้เปลี่ยนการแตะเป็นการคลิกและการเลื่อน และใช้ทำให้ Dock อยู่ที่เดิม

แอปฝั่ง Mac ไม่ต่ออินเทอร์เน็ตเลย แอปฝั่งแท็บเล็ตติดต่อ Google Play เรื่องการซื้อเท่านั้น อ่านเพิ่มที่ [PRIVACY.md](PRIVACY.md)

## บอกกันตรงๆ

- **ใช้สายอย่างเดียว** ไม่มีโหมดไร้สาย ตั้งใจให้เป็นแบบนี้
- **ทีละหนึ่งแท็บเล็ต** เครื่องที่สองต้องรอ
- **เฉพาะ Mac ที่ใช้ชิป Apple Silicon** ในตอนนี้
- **เสียงออกที่ Mac** Cord ส่งเฉพาะภาพ
- **จะโอนไฟล์เข้าแท็บเล็ต** ระหว่างที่ Cord เปิดอยู่บน Mac แท็บเล็ตที่ใช้เป็นจอจะไม่ขึ้นให้โอนไฟล์ ให้ปิด Cord ก่อนแล้วเสียบสายใหม่
- **เสียบสายแล้วไม่มีอะไรเกิดขึ้น** เปิด Cord บนแท็บเล็ต ถ้าหน้าต่างบน Mac มีปุ่ม **Use “…” as a Display** ให้กดหนึ่งครั้ง
- **ภาพเพี้ยนบนแท็บเล็ตบางรุ่น** บางรุ่นถอดรหัส H.264 ได้ดีกว่า HEVC เปิด Terminal แล้วพิมพ์ `defaults write com.nonbannawat.cord codec avc` จากนั้นต่อใหม่
